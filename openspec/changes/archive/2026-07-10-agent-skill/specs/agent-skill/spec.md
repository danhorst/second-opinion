# agent-skill

## ADDED Requirements

### Requirement: Canonical skill ships with the binary
The repository SHALL hold one canonical skill document, and the binary SHALL embed it, so an installed binary can produce the skill without network or repository access.
The embedded copy MUST be byte-identical to the repository copy.

#### Scenario: Embedded copy matches the repository
- **WHEN** the test suite compares the embedded skill against `skills/second-opinion/SKILL.md`
- **THEN** they are identical

### Requirement: Skill content covers invocation and triage
The skill SHALL teach a calling agent: how to invoke the CLI (targets, provider selection, model forcing, prompt override), how to interpret exit codes and the provenance line, that the reviewer should differ from the material's author model, and the triage discipline — cluster, dedupe against the document, rank by severity times novelty, split by altitude, name the spec-gaps — with the expectation that most raw output falls away.
The content MUST be provider-neutral: no provider is presented as the default or home reviewer.

#### Scenario: Provider-neutral wording
- **WHEN** the skill names providers
- **THEN** it presents them as a set the agent chooses from, never one as the tool's default

### Requirement: Per-harness installation
`second-opinion skill install` SHALL write the skill natively for Claude Code (`~/.claude/skills/second-opinion/SKILL.md`, verbatim) and Codex (`~/.codex/prompts/second-opinion.md`, body only), defaulting to all targets, selectable via `--harness`.
For Antigravity, which consumes Claude-format plugins (not bare skills), the installer SHALL write a minimal plugin (`plugin.json` plus the skill) under `~/.second-opinion/antigravity-plugin` and run `agy plugin install <dir>` when `agy` is on PATH, printing the command as a next step when it is not.
`--stdout` SHALL print the canonical skill instead of installing, for any other harness.

#### Scenario: Default install reaches all harnesses
- **WHEN** `skill install` runs with no flags
- **THEN** the Claude and Codex files are written, the Antigravity plugin directory is written, and the plugin install runs or is printed as a next step

#### Scenario: Stdout escape hatch
- **WHEN** `skill install --stdout` runs
- **THEN** the canonical skill is printed to stdout and no file is written

### Requirement: Installed files are owned and idempotent
Installed files SHALL be stamped as generated by the tool, and reinstalling SHALL overwrite them without touching anything else in the target directories.
Target directories SHALL be created as needed.

#### Scenario: Reinstall overwrites cleanly
- **WHEN** `skill install` runs twice, with an unrelated file present in a target directory
- **THEN** the tool's files match the latest content and the unrelated file is untouched
